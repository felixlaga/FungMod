# Getting Support

Thanks for using FungMod. This page explains where to get help and how to get a
useful answer quickly.

## Before you ask

1. Read the [documentation](https://fungmod.readthedocs.io/), especially the
   [Quickstart](https://fungmod.readthedocs.io/quickstart/) and the
   [Scientific user guide](https://fungmod.readthedocs.io/user-guide/).
2. Check the [capability map](https://fungmod.readthedocs.io/capabilities/) to
   confirm the behaviour you need is implemented and what its maturity label is.
3. Search [existing issues](https://github.com/felixlaga/FungMod/issues?q=is%3Aissue)
   and [discussions](https://github.com/felixlaga/FungMod/discussions) to see if
   your question has already been answered.

## Where to ask

| I want to…                                            | Use this                                                                 |
| ----------------------------------------------------- | ------------------------------------------------------------------------ |
| Ask a "how do I…?" or usage question                  | [GitHub Discussions](https://github.com/felixlaga/FungMod/discussions)   |
| Report a bug or unexpected result                     | [Bug report issue](https://github.com/felixlaga/FungMod/issues/new/choose) |
| Request a feature, mechanism, or dataset              | [Feature request issue](https://github.com/felixlaga/FungMod/issues/new/choose) |
| Report a security vulnerability                        | See [SECURITY.md](SECURITY.md) — **do not** open a public issue          |
| Contribute code, docs, or data                        | See [CONTRIBUTING.md](CONTRIBUTING.md)                                    |

If GitHub Discussions is not enabled on the repository, open a **question**
issue from the [issue chooser](https://github.com/felixlaga/FungMod/issues/new/choose)
instead.

## How to ask a good question

A good report gets a good answer. Please include:

- **What you were trying to do** (the scientific or software goal).
- **The exact code** you ran — a minimal, self-contained snippet.
- **What you expected** and **what happened**, including the full traceback.
- **Your environment**: output of `python -c "import fungmod, sys; print(fungmod.__version__, sys.version)"`
  and your operating system.
- **The configuration or registry files** involved, if the problem is
  data-dependent (redact anything confidential).

## Response expectations

FungMod is maintained on a best-effort basis. There is no service-level
agreement. Issues and discussions are triaged as time allows; clear, reproducible
reports are handled first.
