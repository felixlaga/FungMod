# Validation Experiment Datasets

No independent validation datasets are included yet.

This folder is reserved for datasets with `maturity: validated` or datasets
used only as independent validation splits after calibration. A dataset placed
here must include complete source/provenance metadata, explicit units,
measurement definitions, uncertainty behavior, and preprocessing notes.

Synthetic train/validation split tests currently live under
`data/experiments/synthetic/` and do not represent empirical validation.
