FungMod already has a strong foundation: registry-backed cases, uncertainty sampling, standard virtual-experiment tables, preflight diagnostics, modelability outputs, explicit thermodynamic validators, configured thermodynamic JSON/CSV summaries, and scoped notebooks for Reaction 618 and BIO-001.

The biggest remaining gap is not validation data. The biggest gap is breadth and depth of implemented virtual-experiment capability: reusable biology process laws, richer environment/thermodynamics integration, better researcher-facing reports, and notebooks that show the project as a product rather than a set of internal fixtures.

5. Phase Completion Criteria

PRODUCT-001 can be called complete when:

  • Researcher can run source/substrate/environment grids through the top-level API.
  • Outputs include degradation curves, product release, rates, threshold times, uncertainty summaries, provenance, assumptions, missing mechanisms, and limitations.
  • Blocked cases can write useful preflight/report outputs without simulating.
  • Environment ranking is allowed only when explicit response laws or condition-specific records make it meaningful.

THERMO-003 can be called complete for a scoped milestone when:

  • Explicit Gibbs/entropy diagnostics are available in configured and virtual-experiment outputs.
  • Missing Q/T/activity metadata remains explicit.
  • Any solver-time constraint is added only after a tested equation and required state mapping exist.

BIO-003 can be called complete for a scoped milestone when:

  • At least one new reusable process-law family is implemented in code.
  • It has provenance/maturity-labelled parameters and limitations.
  • It has tests using materially different non-specific cases.
  • It is exposed through configured and/or registry-backed virtual-experiment paths.

VALIDATION-DATA-001 should start only when:

  • The simulated output columns match a candidate observation table.
  • The candidate has source-backed numeric time-course rows and extraction/preprocessing notes.
  • The comparison report can state residuals and limitations without overclaiming.

6. Recommended Immediate Next PR

PR-14 recommendation: create the BIO-003 scope/proposal PR before implementing more code. The proposal should choose one generic mechanism family, likely product inhibition or enzyme inactivation, and define exact equations, required parameters, maturity labels, limitations, and two non-specific tests.

This keeps the project moving toward “more biology” without falling into case-specific shortcuts or invented fungal physiology. It also creates a clean basis for the first BIO-003 notebook.
