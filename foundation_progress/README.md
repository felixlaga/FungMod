# Foundation Progress

Start here:

- `../AGENTS.md`
- `FUNGMOD_CENTRAL_GOAL_VIRTUAL_EXPERIMENTS.md`
- `FUNGMOD_NEXT_PHASES_ROADMAP.md`

The central directive is the active implementation guide. The next-phases
roadmap defines the current milestone order; implement only the next open
milestone unless a later phase is explicitly unblocked. Verify roadmap status
against `../progress.md`, code, and tests before assuming a phase gate is
current.

Current biology rule: biology may be added only when the mechanism is
explicitly implemented, provenance-backed, maturity-labelled, tested, and
honest about assumptions and limitations. Unsupported, invented, silently
guessed, or falsely validated biology is forbidden.

Validation outputs for the latest review live under `validation/`.

Older foundation-first milestone plans were moved to `old_progress/` and should
be treated as historical context only, not current implementation instructions.
